# counter

Минимальное мобильное приложение-счётчик на React Native и Expo.

## Возможности

- Крупный текст с текущим числом по центру экрана (начальное значение — 0)
- Кнопка **+** — увеличивает значение на 1
- Кнопка **Сброс** — устанавливает значение в 0

## Запуск

```bash
npm install
npm start
```

После запуска откройте приложение в симуляторе (iOS/Android) или отсканируйте QR-код в Expo Go на телефоне.

- **Android:** `npm run android`
- **iOS:** `npm run ios`
